## 📖 About

Over the years, I've repeatedly searched for the same commands, scripts, and solutions.

* MongoDB dump & restore
* Docker cleanup
* Git recovery
* Redis troubleshooting
* SSL certificate generation
* VS Code & Rider shortcuts
* Linux administration
* PowerShell & Bash automation

Instead of searching the web every time, I decided to build a well-organized engineering toolbox.

This repository contains practical notes and scripts that I personally use during software development and production support.

> **No tutorials. No fluff. Just practical engineering knowledge.**
