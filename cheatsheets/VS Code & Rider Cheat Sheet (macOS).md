# VS Code & Rider Cheat Sheet (macOS)

> macOS shortcuts. `⌘` = Command, `⌥` = Option, `⌃` = Control, `⇧` = Shift.

---

# Search & Replace

| Action                    | VS Code | Rider   |
| ------------------------- | ------- | ------- |
| Find in current file      | `⌘ F`   | `⌘ F`   |
| Replace in current file   | `⌥ ⌘ F` | `⌘ R`   |
| Find in all files         | `⇧ ⌘ F` | `⇧ ⌘ F` |
| Replace in all files      | `⇧ ⌘ H` | `⇧ ⌘ R` |
| Go to file                | `⌘ P`   | `⇧ ⌘ O` |
| Recent files              | `⌃ R`   | `⌘ E`   |
| Go to line                | `⌃ G`   | `⌘ L`   |
| Command Palette / Actions | `⇧ ⌘ P` | `⇧ ⌘ A` |
